## 一、项目概述

本项目是一个基于 **AI-TDD（测试驱动开发）** 方法论的**植物大战僵尸**游戏实现项目。项目采用模块化架构设计，将游戏功能划分为8个主要模块，包含20个具体任务。

### 项目特点
- **技术栈**: HTML5 Canvas + JavaScript
- **架构模式**: 模块化、事件驱动
- **开发方法**: 测试驱动开发（TDD）
- **游戏类型**: 塔防策略游戏
