# AITDD 用户手册

## 简介

AITDD 是一个 AI 辅助的可视化任务治理系统，帮助您管理项目任务、追踪依赖关系，并与 AI 编程助手协作。

## 快速开始

### 安装

1. 确保已安装 Go 1.21+ 和 Node.js 18+
2. 克隆项目仓库
3. 运行安装脚本

### 启动服务

**Windows:**
```batch
start-backend.bat
start-frontend.bat
```

**手动启动:**
```bash
# 后端
cd backend
go run ./cmd/aitdd serve

# 前端
cd frontend
npm run dev
```

### 访问界面

打开浏览器访问 http://localhost:5173

## 主要功能

### 项目管理

1. **创建项目**
   - 点击左侧导航栏的"新建项目"
   - 填写项目名称、描述和路径
   - 点击"创建"

2. **项目列表**
   - 查看所有项目
   - 搜索和筛选项目
   - 进入项目详情

### 模块管理

1. **创建模块**
   - 选择项目后点击"新建模块"
   - 设置模块名称和描述
   - 可选择父模块创建层级结构

2. **模块树**
   - 查看模块的树形结构
   - 展开/折叠子模块
   - 拖拽调整模块顺序

### 任务管理

1. **创建任务**
   - 选择模块后点击"新建任务"
   - 填写任务标题和描述
   - 设置优先级和状态

2. **任务状态**
   - pending - 待处理
   - in_progress - 进行中
   - completed - 已完成
   - blocked - 已阻塞
   - cancelled - 已取消

3. **任务契约**
   - 定义任务的输入要求
   - 定义任务的输出产物
   - 帮助 AI 理解任务边界

### 依赖关系

1. **创建依赖**
   - 在任务详情中点击"添加依赖"
   - 选择依赖的任务
   - 选择依赖类型

2. **依赖类型**
   - Finish-to-Start (FS) - 前置任务完成后开始
   - Start-to-Start (SS) - 前置任务开始后开始
   - Finish-to-Finish (FF) - 前置任务完成后完成

3. **循环检测**
   - 系统自动检测循环依赖
   - 发现循环时会阻止创建

### 任务可视化

1. **任务图**
   - 查看任务的网络图
   - 拖拽节点调整布局
   - 点击节点查看详情

2. **迷你地图**
   - 快速导航大型任务图
   - 缩放和平移

### 资源锁定

1. **锁定任务**
   - 点击任务旁的"锁定"按钮
   - 输入您的代理标识
   - 锁定后其他用户无法修改

2. **解锁任务**
   - 只有锁定者可以解锁
   - 点击"解锁"按钮释放

### 通知系统

1. **查看通知**
   - 点击右上角的通知图标
   - 查看未读通知列表

2. **通知类型**
   - 任务完成通知
   - 任务阻塞提醒
   - 系统消息

## AI 编程助手集成

### Cursor / KiloCode

1. 运行 `aitdd init` 初始化项目
2. 选择您的 AI 编程工具
3. 生成的配置文件会自动创建

### MCP 接口

AITDD 提供 MCP (Model Context Protocol) 接口：
- API 端点: http://localhost:34567/api/v1
- WebSocket: ws://localhost:34567/ws

## 数据同步

### 配置同步

1. 进入"设置" > "数据同步"
2. 输入远程数据库地址
3. 设置同步间隔
4. 启用自动同步

### 解决冲突

1. 当检测到数据冲突时会显示提示
2. 选择保留本地版本、远程版本或合并
3. 确认解决后继续同步

## 常见问题

### Q: 如何重置密码？

A: AITDD 使用本地数据库，无需密码登录。

### Q: 数据存储在哪里？

A: 数据存储在项目目录下的 SQLite 数据库文件中。

### Q: 如何备份数据？

A: 复制项目目录下的 `.aitdd` 文件夹即可。

### Q: 支持多人协作吗？

A: 支持通过资源锁定机制进行协作，防止同时编辑同一任务。
